1. Tailwind CSS คืออะไร?

Tailwind CSS เป็นเครื่องมือสร้าง CSS แบบ utility-first แต่ละ class ใช้จัดการหน้าที่เล็ก ๆ เช่น ระยะห่าง สี หรือขนาดตัวอักษร เรานำหลาย class มาประกอบกันบน HTML เพื่อสร้างหน้าตาที่ต้องการ

CSS แบบเขียนเอง

ตั้งชื่อ class เช่น button-primary แล้วเขียนกฎ CSS สำหรับ class นั้นแยกไว้

Tailwind แบบ utility

ประกอบ class เช่น bg-cyan-700 text-white px-4 py-2 เพื่อกำหนดสีและระยะห่างโดยตรง

Tailwind ช่วยให้ใช้ชุดค่าที่สม่ำเสมอและปรับหน้าตาได้ใกล้กับโครงสร้าง HTML แต่ยังต้องเข้าใจ CSS เช่น box model, flex และ grid หากยังไม่คุ้น แนะนำอ่าน บทเรียน CSS ควบคู่กัน

อ่าน class ทีละชิ้น

<button class="rounded-lg bg-cyan-700 px-4 py-2 text-white">
  เริ่มเรียน
</button>

rounded-lg ทำมุมมน, bg-cyan-700 กำหนดพื้นหลัง, px-4 และ py-2 เพิ่ม padding แนวนอนและแนวตั้ง ส่วน text-white กำหนดสีข้อความ

Tailwind ทำงานอย่างไร: เครื่องมือจะสแกนไฟล์ต้นทางเพื่อหาชื่อ class แล้วสร้าง CSS สำหรับ class ที่พบ ตัวเบราว์เซอร์จึงได้รับ CSS ปกติ ไม่ได้แปลชื่อ class เอง

2. เริ่มโปรเจกต์ด้วย Vite + Tailwind v4

ตัวอย่างนี้ใช้ Vite แบบ Vanilla JavaScript เพื่อให้เห็นขั้นตอนชัดเจน ต้องติดตั้ง Node.js และ npm ที่รองรับ Vite รุ่นที่ใช้อยู่ก่อน ตรวจสอบได้ด้วย node -v และ npm -v จากนั้นรันคำสั่งใน terminal

npm create vite@latest tailwind-demo -- --template vanilla
cd tailwind-demo
npm install
npm install tailwindcss @tailwindcss/vite

เพิ่มไฟล์ vite.config.js ที่รากโปรเจกต์ หากมีไฟล์ config อยู่แล้ว ให้เพิ่ม plugin ลงใน config เดิมแทนการลบค่าอื่น

import { defineConfig } from 'vite'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [tailwindcss()],
})

แทนที่เนื้อหา style.css ในรากโปรเจกต์ด้วยคำสั่งนี้ และตรวจสอบว่า main.js ยังคงมี import './style.css' อยู่

@import "tailwindcss";

แทนที่เนื้อหา index.html ด้วยตัวอย่างด้านล่าง โดยคง script ที่โหลด main.js ไว้ เพื่อให้ CSS ถูกนำเข้า

<!doctype html>
<html lang="th">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Tailwind Demo</title>
  </head>
  <body class="bg-slate-100 p-8">
    <h1 class="text-3xl font-bold text-cyan-700">สวัสดี Tailwind!</h1>
    <script type="module" src="/main.js"></script>
  </body>
</html>

ไฟล์ main.js ที่ Vite สร้างมาอาจมีโค้ดตัวอย่างซึ่งอ้างถึง element ที่เราแทนที่ไปแล้ว ให้แทนที่เนื้อหาไฟล์ด้วยบรรทัดเดียวนี้:

import './style.css'
npm run dev

เปิด URL ที่ terminal แสดง ควรเห็นหัวข้อสีฟ้าเข้มบนพื้นหลังสีอ่อน เมื่อพร้อมสร้างไฟล์สำหรับเผยแพร่ให้ใช้ npm run build ผลลัพธ์อยู่ใน dist/ และทดลอง build ในเครื่องด้วย npm run preview

ระวังเวอร์ชัน: บทเรียนนี้ใช้ v4 ซึ่งใช้ @import "tailwindcss"; และ Vite plugin ตัวอย่างเก่าที่ใช้ @tailwind base หรือสร้าง config ด้วย tailwindcss init เป็นแนวทาง v3 อย่านำมาปะปนกันโดยไม่ตรวจเวอร์ชัน

3. รู้จัก utility ที่ใช้บ่อย

ชื่อ class มักประกอบด้วยหมวดและค่า เช่น p-4 หมายถึง padding รอบด้าน; text-lg หมายถึงขนาดข้อความ ส่วน text-slate-700 หมายถึงสีข้อความ ความหมายจึงขึ้นอยู่กับชื่อค่าที่ตามมา

หมวดตัวอย่างความหมาย
ระยะห่างp-4, px-6, mt-4, gap-4padding รอบด้าน, padding ซ้ายขวา, margin ด้านบน และช่องว่างระหว่างรายการ
ขนาดw-full, max-w-md, h-12กว้างเต็มพื้นที่พ่อ, จำกัดความกว้างสูงสุด, กำหนดความสูง
ตัวอักษรtext-xl, font-bold, text-centerขนาดตัวอักษร, น้ำหนัก และการจัดแนว
สีbg-white, text-slate-700, border-cyan-500พื้นหลัง สีข้อความ และสีเส้นขอบ
รูปทรงborder, rounded-xl, shadow-mdเส้นขอบ มุมมน และเงา

ค่า spacing เริ่มต้นอิงหน่วย 0.25rem เช่น p-4 เท่ากับ 1rem (โดยทั่วไป 16px เมื่อขนาดตัวอักษรรากเป็น 16px) ค่าของ theme ปรับได้ จึงไม่ควรจำว่าเลขทุกตัวเป็น pixel เสมอไป

ตัวอย่างการ์ด

เริ่มต้นกับ Tailwind

ประกอบ utility ทีละส่วน แล้วสังเกตผลที่เปลี่ยนไป

เริ่มเรียน

ภาพตัวอย่างนี้จำลองด้วย CSS ในบทเรียน จึงเปิดอ่านได้โดยไม่ต้องเชื่อมต่อหรือ build โปรเจกต์

<article class="max-w-sm rounded-2xl bg-white p-6 shadow-lg">
  <h3 class="text-lg font-bold text-slate-900">เริ่มต้นกับ Tailwind</h3>
  <p class="mt-2 text-slate-600">ประกอบ utility ทีละส่วน แล้วสังเกตผลที่เปลี่ยนไป</p>
  <button class="mt-4 rounded-lg bg-cyan-700 px-4 py-2 font-bold text-white">
    เริ่มเรียน
  </button>
</article>

4. จัด Layout ด้วย Flex และ Grid

Flexbox เหมาะกับการจัดรายการตามแนวหลักหนึ่งแนว เช่น เมนู ส่วน Grid เหมาะกับการกำหนดแถวและคอลัมน์ เช่น รายการการ์ด

Flex: จัดหัวข้อกับปุ่มให้อยู่คนละด้าน

<div class="flex items-center justify-between gap-4">
  <h2 class="text-xl font-bold">บทเรียนล่าสุด</h2>
  <a href="#courses" class="text-cyan-700 underline">ดูทั้งหมด</a>
</div>

flex เริ่มใช้ Flexbox; items-center จัดกึ่งกลางตามแนวขวาง; justify-between กระจายพื้นที่ระหว่างรายการ และ gap-4 เว้นช่องว่างขั้นต่ำระหว่างรายการ

Grid: เรียงการ์ด

<div class="grid grid-cols-1 gap-4 md:grid-cols-2 lg:grid-cols-3">
  <article class="rounded-xl bg-white p-6 shadow">บทที่ 1</article>
  <article class="rounded-xl bg-white p-6 shadow">บทที่ 2</article>
  <article class="rounded-xl bg-white p-6 shadow">บทที่ 3</article>
</div>

เริ่มต้นหนึ่งคอลัมน์ เมื่อหน้าจอถึง md จะมีสองคอลัมน์ และเมื่อถึง lg จะมีสามคอลัมน์

5. Responsive: เริ่มจากมือถือก่อน

class ที่ไม่มี prefix ใช้ทุกขนาด ส่วน md: ทำงานเมื่อหน้าจอกว้างถึง breakpoint นั้น และกว้างกว่านั้น ไม่ได้หมายถึงเฉพาะแท็บเล็ต

Prefixความกว้างขั้นต่ำเริ่มต้นโดยประมาณเมื่อ 1rem = 16px
sm:40rem640px
md:48rem768px
lg:64rem1024px
xl:80rem1280px
2xl:96rem1536px
<div class="flex flex-col gap-4 md:flex-row md:items-center">
  <h2 class="text-xl md:text-2xl">สวัสดี</h2>
  <p>มือถือเรียงลง จอที่กว้างตั้งแต่ md เรียงแนวนอน</p>
</div>

เริ่มกำหนดหน้าตามือถือด้วย flex-col แล้วเพิ่ม md:flex-row สำหรับจอที่กว้างขึ้น ลองย่อและขยายหน้าต่างเบราว์เซอร์เพื่อดูจุดเปลี่ยน

6. สถานะผู้ใช้และ Dark mode

เติม prefix เช่น hover:, focus-visible: หรือ disabled: เพื่อให้ utility ทำงานเมื่อ element อยู่ในสถานะนั้น

<button type="button" class="rounded-lg bg-cyan-700 px-4 py-2 text-white
  hover:bg-cyan-800 focus-visible:outline-2 focus-visible:outline-offset-2
  focus-visible:outline-cyan-700 disabled:cursor-not-allowed disabled:opacity-50">
  บันทึก
</button>

hover: เปลี่ยนสีเมื่อชี้เมาส์ ส่วน focus-visible: ช่วยให้เห็นตำแหน่งเมื่อใช้คีย์บอร์ด และ disabled: ทำงานเมื่อปุ่มมี attribute disabled จริง ไม่ได้ปิดปุ่มให้เอง

Dark mode

<div class="bg-white p-6 text-slate-900 dark:bg-slate-900 dark:text-white">
  เนื้อหาที่ปรับสีตามโหมดของระบบ
</div>

ค่าเริ่มต้นของ dark: อิงการตั้งค่าสีของระบบผ่าน prefers-color-scheme ถ้าต้องการปุ่มสลับเอง ต้องปรับ dark variant และเขียนโค้ดจัดการสถานะเพิ่มเติมตาม เอกสาร Dark mode

สีและเอฟเฟกต์ไม่ควรเป็นสัญญาณเดียวที่บอกสถานะ ใช้ข้อความหรือสัญลักษณ์ประกอบ ตรวจสอบความคมชัดของสี และลองใช้งานด้วยคีย์บอร์ดเสมอ

7. ปรับ Theme และใช้ค่าที่กำหนดเอง

ใน v4 สามารถเพิ่ม design token ใน CSS ด้วย @theme ตัวอย่างนี้สร้างสีชื่อ brand ทำให้ใช้ utility อย่าง bg-brand และ text-brand ได้

/* style.css */
@import "tailwindcss";

@theme {
  --color-brand: #0e7490;
}
<button class="rounded-lg bg-brand px-4 py-2 text-white">เริ่มต้น</button>

หากต้องใช้ค่าพิเศษเพียงจุดเดียว ใช้ arbitrary value เช่น max-w-[42rem] หรือ bg-[#0e7490] ได้ แต่ค่าที่ใช้ซ้ำหลายที่ควรตั้งเป็น theme เพื่อแก้ไขและดูแลได้ง่าย

React และชื่อ class ที่เปลี่ยนตามข้อมูล

ใน JSX ใช้ className แทน class และระบุชื่อ class ให้ครบใน source เพราะ Tailwind สแกนเป็นข้อความ ไม่สามารถคาดเดาชื่อที่ประกอบขึ้นระหว่างรันได้

// ไม่ควร: Tailwind อาจไม่พบ class ที่ประกอบขึ้นภายหลัง
const className = `bg-${color}-600`

// ควร: ระบุชื่อ class ทั้งหมดให้สแกนพบ
const colors = { primary: 'bg-cyan-700', danger: 'bg-red-700' }
<button className={`${colors.primary} rounded-lg px-4 py-2 text-white`}>
  บันทึก
</button>

8. ลงมือสร้างหน้ารายการคอร์ส

ใช้โปรเจกต์จากบทที่ 2 แทนที่ index.html ด้วยโค้ดด้านล่าง แล้วรัน npm run dev การ์ดจะเรียงหนึ่งคอลัมน์บนมือถือและสามคอลัมน์ตั้งแต่ md ขึ้นไป ลองเปลี่ยนสีและย่อหน้าจอเพื่อสังเกตผล

<!doctype html>

  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>คอร์สสำหรับนักพัฒนา</title>
</head>
<body class="min-h-screen bg-slate-100 text-slate-900">
  <header class="bg-cyan-800 text-white">
    <div class="mx-auto max-w-5xl px-6 py-10">
      <p class="font-semibold text-cyan-100">LEARNING HUB</p>
      <h1 class="mt-2 text-3xl font-bold md:text-4xl">เริ่มเรียนเขียนเว็บ</h1>
      <p class="mt-3 text-cyan-50">เลือกหัวข้อที่สนใจ แล้วค่อย ๆ ฝึกไปด้วยกัน</p>
    </div>
  </header>
  <main id="courses" class="mx-auto max-w-5xl px-6 py-10">
    <h2 class="text-2xl font-bold">คอร์สแนะนำ</h2>
    <div class="mt-6 grid gap-4 md:grid-cols-3">
      <article class="rounded-xl bg-white p-6 shadow-sm">
        <h3 class="text-lg font-bold">HTML</h3>
        <p class="mt-2 text-slate-600">เรียนรู้โครงสร้างของหน้าเว็บ</p>
      </article>
      <article class="rounded-xl bg-white p-6 shadow-sm">
        <h3 class="text-lg font-bold">CSS</h3>
        <p class="mt-2 text-slate-600">จัดรูปแบบและ layout ให้สวยงาม</p>
      </article>
      <article class="rounded-xl bg-white p-6 shadow-sm">
        <h3 class="text-lg font-bold">Tailwind CSS</h3>
        <p class="mt-2 text-slate-600">สร้างหน้าตาด้วย utility classes</p>

  <script type="module" src="/main.js"></script>
</body>
</html>

mx-auto max-w-5xl จำกัดความกว้างและจัดกึ่งกลาง, px-6 กันเนื้อหาชิดขอบ ส่วน grid gap-4 md:grid-cols-3 สร้าง grid ที่มีช่องว่างและเปลี่ยนเป็นสามคอลัมน์เมื่อจอกว้างพอ

9. แบบฝึกหัด

  1. สร้างปุ่มพื้นหลังสีฟ้า ข้อความสีขาว มีมุมมนและเปลี่ยนสีเมื่อชี้เมาส์ เพิ่มเส้นแสดง focus สำหรับคีย์บอร์ด
  2. สร้างรายการการ์ดสี่ใบ ให้มือถือมีหนึ่งคอลัมน์ ตั้งแต่ sm มีสอง และตั้งแต่ lg มีสี่คอลัมน์
  3. ต่อยอดโปรเจกต์คอร์ส: เพิ่มการ์ดใหม่ ปรับพื้นที่ด้านใน และทำให้สีพื้นหลังกับข้อความรองรับ dark mode

10. ปัญหาที่พบบ่อยและแนวทางต่อยอด

class ไม่แสดงผล

ตรวจว่ารัน dev server แล้ว มี plugin ใน Vite config และ main.js import ไฟล์ CSS ที่มี @import "tailwindcss"; รวมถึงไฟล์ที่ใช้ class อยู่ในพื้นที่ที่ Tailwind สแกน

สร้างชื่อ class จากตัวแปรแล้วไม่ทำงาน

เขียนชื่อเต็มแต่ละทางเลือกใน source เช่น bg-red-700 และ bg-cyan-700 แล้วเลือกจาก object แทนการต่อสตริง

Responsive ไม่เปลี่ยน

ตรวจ viewport meta tag และความกว้างจริงของหน้าต่าง จำว่า md: เริ่มที่ 48rem ไม่ใช่กฎสำหรับจอเล็กกว่า

สไตล์ชนกัน
